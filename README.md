# GeoLite.mmdb 数据库仓库
本仓库自动同步 MaxMind 官方的 GeoLite2 数据库，包含 ASN 和国家地理信息。

## 📅 最新更新时间
2026.02.22

## 📁 包含的数据库文件
共 2 个文件：GeoLite2-ASN.mmdb,GeoLite2-Country.mmdb,

## 🚀 下载方式
1. **Release 页面**：[最新版本](https://github.com/gift95/GeoIP/releases/tag/latest)
2. **直接下载**：
   - [GeoLite2-ASN.mmdb](https://github.com/gift95/GeoIP/releases/download/latest/GeoLite2-ASN.mmdb)
   - [GeoLite2-Country.mmdb](https://github.com/gift95/GeoIP/releases/download/latest/GeoLite2-Country.mmdb)

## ⚙️ 自动更新
仓库每 7 天自动从 MaxMind 官网同步最新数据库，并更新 Release 和 `latest` 标签。

## 📄 许可证
本仓库的数据库文件遵循 MaxMind 官方的 [GeoLite2 许可证](https://www.maxmind.com/en/geoip2-geolite2-license)。
